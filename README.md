# Nebelkind Website

Die Startseite unter **https://schlimmtendo.github.io/**.

Dieses Repository (`schlimmtendo/schlimmtendo.github.io`) enthält ausschließlich die Website. Die Kodi-Addons, Repository-Metadaten und der Installer liegen separat unter `schlimmtendo/nebelkind.repo`.

Die Download-Links in der Website verweisen direkt auf die veröffentlichten Dateien in:
`https://raw.githubusercontent.com/schlimmtendo/nebelkind.repo/main/packages/`

## Aktivierung
1. Repository `schlimmtendo.github.io` erstellen (Public).
2. Diese Dateien auf den Branch `main` hochladen.
3. In GitHub `Settings → Pages → Build and deployment → Deploy from a branch` auswählen, `main` und `/(root)` einstellen.

**Wichtig:** Die Kodi-Pakete müssen zunächst in `nebelkind.repo/main/packages/` veröffentlicht sein, sonst geben die Download-Links 404 zurück.
